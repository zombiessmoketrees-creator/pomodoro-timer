# Motion graphics (Bang Motion)

Browser-built openers made with the [Bang Motion](https://github.com/bangtutorial/bang-motion) skill (MIT).
Each folder is one deliverable: a single `index.html` that autoplays and loops — double-click to watch.

- `?debug=1` shows a scrub bar · Space pause · R restart
- Fonts and GSAP load from a CDN, so the page needs internet to play
- `score.mp3` is synthesised in code (`engine/narrate.py` chiptune), not a cloud service

| Folder | What | Format |
|---|---|---|
| `mothman-opener/` | The Mothman of Point Pleasant — one continuous night-road shot, title in the eye | 9:16 1080×1920, 26.5 s |

The MP4 export goes to `output/motion/` (git-ignored).
